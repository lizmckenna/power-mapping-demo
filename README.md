# Power Mapping Instrument — demo

Interactive prototype of a power-mapping instrument for organizing research.

Two views of the same data:
- **Network** — ego-centric force-directed graph. The participating organization sits at the center; power actors are arrayed around it. Edge weight encodes the highest face of power engaged (decision-making, agenda, ideological).
- **Power grid** — actors plotted on the Cushman (2014 / 2023) 2x2: Opponent ↔ Supporter on the x-axis, Not Powerful ↔ Powerful on the y-axis. Quadrants labeled with the corresponding strategies (organize a base, divide & neutralize, engage & redirect, disorganize / reorganize).

Demo only — no auth, no backend, no persistence. Includes seed data and an Export JSON button.
